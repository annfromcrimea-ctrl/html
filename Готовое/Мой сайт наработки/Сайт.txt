Создай сайт оператора персональных данных (152-ФЗ) на русском языке.
Чистый HTML/CSS/JS без фреймворков. Каждый файл выдай ОТДЕЛЬНЫМ кодовым
блоком с названием файла. В начале ответа — простая инструкция, как
сохранить файлы через Блокнот в кодировке UTF-8.

═══ ФАЙЛЫ ═══
1. index.html — ВЕСЬ сайт в одном файле.
2. photo.svg — заглушка фото (зелёный силуэт с подписью «ВАШЕ ФОТО»).
3. _headers — защитные HTTP-заголовки для Netlify (X-Frame-Options: DENY,
   X-Content-Type-Options: nosniff, HSTS, Referrer-Policy, Permissions-Policy).
4. cloud-function/function.py — серверлесс-функция Яндекс Облака (Python 3.11):
   пишет данные в две Яндекс Таблицы через API (IAM-токен из метаданных).
5. README.md — инструкция простыми словами + чек-лист РКН/ФАС.

═══ ГЛАВНОЕ: РЕДАКТИРУЕМОСТЬ ═══
Все тексты, ссылки и фото — ТОЛЬКО в одном блоке «НАСТРОЙКИ» в конце
index.html. Ключи на русском (имя, инн, email, адрес, фото, документы:[...],
сообщества:[...], занятия:[...], время_записи:[...], адрес_функции:"").
Заглушки в [квадратных скобках]. Всё ниже блока помечено «ДАЛЬШЕ МЕНЯТЬ
НЕ НУЖНО». Фото — ОРИГИНАЛЬНОЕ (файл пользователя), меняется одной строкой;
если файла нет — показывается запасная заглушка, сайт не ломается.

═══ СТРУКТУРА (две «страницы» в одном файле, переключение кнопками) ═══
СТРАНИЦА 1 «Согласие и доступ» — воронка из 4 шагов:
 01 превью-текст о владельце и сообществах;
 02 документы оператора: список с кнопкой «Открыть» и чекбоксом
    «Ознакомлен(а)»; шаг 03 заблокирован, пока не отмечены ВСЕ;
 03 форма: Имя*, Фамилия*, E-mail (необязательно), чекбокс согласия
    (текст собирается автоматически из реквизитов оператора, цель — доступ)
    + ОТДЕЛЬНЫЙ необязательный чекбокс согласия на рассылку;
 04 закрытые сообщества: до согласия скрыты (плашка «Доступ закрыт»),
    после — штамп «Зарегистрировано», № согласия ПД-ГГГГ-XXXX, дата/время,
    карточки-ссылки сообществ и баннер «Записаться на занятия».
СТРАНИЦА 2 «Запись на занятия»:
 выбор занятия (карточки-радио), дата (не раньше сегодня) и время (чипы),
 Имя*, Фамилия*, Телефон*, E-mail, комментарий, отдельное согласие на
 запись; после отправки — карточка «Заявка принята» с № ЗН-ГГГГ-XXXX.
Шапка: круглое фото-аватар с мягкой зелёной «кляксой» позади.
Футер: реквизиты оператора, контакт, номер уведомления РКН.
Cookie-баннер со ссылкой на политику cookie — показывается ОТДЕЛЬНЫМ
независимым скриптом. Живые часы (МСК), шкала прогресса шагов, плавные
появления при прокрутке.

═══ ДИЗАЙН ═══
Дружелюбный «Pixar 2D»: мягкие зелёные оттенки (фон #f1f7f2, тёмно-зелёный
#175943, акцент #2f9e68, светло-зелёный #7fd0a4, тёплый жёлтый для деталей),
скруглённые формы, мягкие тени, плавающие листики. Шрифты с кириллицей:
Comfortaa (заголовки), Nunito (текст), JetBrains Mono (метки, номера).
Никакого «канцелярского» серого стиля.

═══ ДАННЫЕ ═══
Обе формы шлют JSON на адрес функции (НАСТРОЙКИ → адрес_функции) с полем
type: "consent" или "booking". Колонки таблиц:
 согласия: Имя|Фамилия|E-mail|Дата согласия|№ согласия|Рассылка;
 записи: Имя|Фамилия|Телефон|E-mail|Занятие|Дата|Время|Комментарий|№ заявки|Отправлена.
Если адрес пуст — демо-режим с жёлтой плашкой-подсказкой.

═══ РКН / ФАС ═══
Раздельные согласия по целям (доступ / рассылка / запись); реквизиты
оператора и контакт на сайте; журнал согласий с датой и временем.
В README напомнить: уведомление РКН до начала обработки, ответственный
за ПД, рассылки только при согласии, без обещаний результата, маркировка
рекламы, оферта при платном доступе.

═══ НАДЁЖНОСТЬ / ЗАЩИТА ═══
Статика на CDN + серверлесс (выдержит наплыв); HTTPS; валидация и
экранирование всех вводов на сайте и в функции; в функции — секрет API_KEY
и проверка домена ALLOWED_ORIGIN; если файл сохранён не в UTF-8 — сайт
показывает подсказку «сохраните в кодировке UTF-8».

Все комментарии в коде — на русском, для человека без опыта.
